# homebrew-tap

```
brew tap porkloin/tap
brew install <formula>
```

## Formulas

| Formula | Description |
| --- | --- |
| [hdrneon](https://github.com/porkloin/hdrneon) | HDR test scene: neon tubes above reference patches, in SDR, HDR10 or scRGB |
| [clickflash](https://github.com/porkloin/clickflash) | Black window that flashes white on every click, for click-to-photon latency |
